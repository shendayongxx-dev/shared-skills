# 硬性合规检查

对每一项输出 `pass/fail`、证据、问题位置和修复建议。无法确认时按失败处理，不以审美判断代替事实检查。

| ID | 检查项 | 通过条件 |
|---|---|---|
| HC-01 | 商品主体保真 | 商品类别、外观、颜色和关键细节未被替换或实质改变 |
| HC-02 | 商品数量 | 商品数量与输入一致；输入未指定时不得制造容易被误解的套装数量。盒、瓶、替换装、附件等多组件必须与数量语义一致，不能因重复包装或镜像造成“多送一件”的错觉 |
| HC-03 | 价格与单位 | 价格、币种、单位、原价和到手价均与输入一致 |
| HC-04 | 促销与时间 | 折扣、满减、赠品、活动时间无缺失、改写或夸大 |
| HC-05 | Logo 与品牌 | 仅使用 `logo_ref` 指向的原始 Logo；未重绘、拉伸、旋转、裁断或替换。`logo_ref` 为空时不得生成独立品牌标；商品包装上已有的商标不构成新增独立 Logo 的授权 |
| HC-06 | 卖点完整 | 必须展示的卖点和法务文字完整，未增加无依据功效 |
| HC-07 | 文字正确 | 无错字、乱码、错误翻译、重复、截断或语义改变 |
| HC-08 | 可读性 | 文字没有被遮挡，字号、对比度和行距足以阅读 |
| HC-09 | 边界与安全区 | 商品、Logo、价格、CTA 和法务文字不越界、不被裁切 |
| HC-10 | 画布与格式 | 最终交付文件的像素宽高、比例、语言和文件格式精确符合输入要求；生成器返回近似尺寸时，先做确定性高质量重采样，再检查安全区和文字可读性 |
| HC-11 | 禁用内容 | 未出现输入及 style guide 明确禁止的元素或表达 |
| HC-12 | protected content | 所有保护内容与输入逐值一致 |

## 路由

- 任一检查失败：生成结构化 `problem_list` 并返回定向重画；
- 重画后：从 HC-01 重新检查全部项目；编辑调用超时或未产出图片时，记录工具错误并在同一目标轮次改用“参考原图 + 完整保护内容 + 单一修复目标”的等价重生成；
- 全部通过：输出；
- 达到上限：选择问题最少且严重度最低的候选，以 `degraded` 状态输出并列明未解决问题。

硬性检查中不得出现“画面不够高级”“审美一般”等主观结论。此类判断属于未来美学 Agent，不属于 1.0。

## 定向重画的计数与兜底

- 只有形成可检查的新候选图时才消耗一次全局重画次数；超时、空结果或不可读文件属于工具错误，不产生候选，也不单独增加次数。
- 首选对上一候选做局部编辑；若编辑能力连续失败或不可用，可在同一目标轮次执行等价重生成。
- 等价重生成必须同时提供原商品参考图、上一候选（若工具支持）、八组 `protected_content`、已锁定维度和唯一修复目标；不得借兜底改变价格、促销、Logo、商品数量或其他受保护事实。
- 新候选生成后先归一化为精确画布尺寸，再执行 HC-01～HC-12 全量复查；不能把“提示词要求已写入”当作通过证据。
