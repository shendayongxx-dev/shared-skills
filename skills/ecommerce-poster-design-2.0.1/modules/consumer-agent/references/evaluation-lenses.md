# P-M-S 评估视角

P 人群、M 购买动机和 S 使用场景来自上游 C 分类库。Agent 只应用标签，不重新分类。

## P 人群

- P01 青年学生与潮流新人：检查新鲜感、颜值、价格可接受度和社交表达是否容易感知。
- P02 职场通勤人群：检查效率、便捷、品质、体面和可靠是否清楚。
- P03 家庭育儿人群：检查安全、健康、耐用、省心和全家使用是否有事实支持。
- P04 成熟品质人群：检查材质、工艺、品牌可信度、体验和长期价值。
- P05 大众务实人群：检查价格、实用功能、耐用和优惠是否直接易懂。
- P06 银发健康人群：检查安全、健康、舒适、可信、易读和易操作。

P 主要作用于“人群与场景适配”，也决定全部信息的可读性门槛。

## M 购买动机

- M01 价格收益：需要价格、优惠、数量、权益、时间或条件等明确证据。
- M02 功能效率：需要功能、使用结果、省时、省力或便利证据。
- M03 品质信任：需要材质、工艺、认证、品牌、耐用或质保证据。
- M04 专业性能：需要专业任务、可比较参数、测试数据或认证证据。
- M05 审美悦己：需要商品造型、色彩、风格、个性表达或愉悦体验。
- M06 情感礼赠：需要赠礼对象、节庆关系、礼盒或情感表达。

M 主要作用于“消费利益与卖点传达”和“购买信心与行动驱动”。只认可输入支持的证据。

## S 使用场景

- S01 居家生活：检查家庭内部的实际使用位置、动作、便利或舒适结果。
- S02 工作学习：检查办公室、会议、校园或学习任务中的商品关系。
- S03 通勤车载：检查移动过程、随身携带、城市交通或车内即时使用。
- S04 户外运动旅行：检查运动、露营、徒步、旅行或短途出游的真实使用联系。
- S05 休闲社交：检查分享、互动、轻松社交与商品社交存在。
- S06 节庆礼赠：检查节庆或正式赠礼语境、对象和礼赠价值。

S 主要作用于“人群与场景适配”。氛围背景本身不足以证明场景成立，商品必须与场景发生真实使用关系。

## 边界

- 画面看起来像另一个人群或场景时，报告“锁定标签表达不足或冲突”，不要改写标签。
- 场景氛围与商品利益是两个问题时可以分别诊断；同一问题不得在多个维度重复扣分。
- 视觉气质只有影响识别、理解、信任或行动时才进入消费者评分，纯美学质量交给美学 Agent。
