# 3.1.0-rc.3 美学优先顺序适配

## 唯一实验变量

基线链路为 `硬合规 → 消费者 → 美学 → 最终质量`；本实验链路为 `硬合规 → 美学 → 消费者 → 最终质量`。模块版本、观察项、计分、阈值、生成器、硬合规、最终质量规则和 8 次全局预算保持不变。

## 为什么不能沿用原消费者锁

基线美学输入要求消费者先通过并提供五维锁。美学先行时这些事实尚不存在。伪造全通过消费者结果会污染自变量，并使首轮美学被不存在的上游结论约束。因此首轮美学只接收当前候选和八组事实保护对象。

## 锁状态机

| 状态 | 已建立的锁 | 允许下一步 |
|---|---|---|
| HC 通过 | 八组保护对象 | 美学评价 |
| 美学失败 | 已达标美学维度 + 八组保护对象 | 仅修失败美学维度 |
| 美学通过 | 六个美学维度 + 八组保护对象 | 消费者评价 |
| 消费者失败 | 六个美学维度 + 已通过消费者维度 + 八组保护对象 | 仅修失败消费者功能 |
| 两者通过 | 六个美学维度 + 五个消费者维度 + 八组保护对象 | 最终质量仲裁 |

锁保护功能与已验证关系，不意味着冻结每个像素。合同必须写出允许编辑对象、禁止变化、基线候选和复检条件。

## 回归定义

- 消费者返图的美学回归：任一六维低于原门槛、出现新关键问题、或八组保护对象发生变化。
- 美学或最终质量返图的消费者回归：在已有消费者通过基线时，任一五维低于 14、出现硬失败、`regressed_dimensions` 非空或保护对象变化。
- 新候选永远重新计分；旧分仅作回归基线，不直接复制为新候选分数。
- 回归候选立即淘汰，不得覆盖最后通过基线，也不得进入下游门禁。

## 路由去环

消费者 A-D-2.0 的通过结果固定返回 `next_route=aesthetic_agent`。在本实验中，宿主根据 `evaluation_order` 将其映射为 `invoke_final_quality_gate`。映射只发生在消费者正式通过、五维全锁、当前候选已有美学 Pass 且绑定一致时；其他情况不得跳转最终质量门。

## 最终质量返图

最终质量门位于两 Agent 之后，因此返图合同同时携带六个美学锁和五个消费者锁。成功返图产生新版本后，按 `HC → 美学 → 消费者 → 最终质量` 重跑，不能只验证缺陷是否消失。
