# 3.1.0-rc.3 no-aesthetic 消融工作流

1. 校验输入并建立八组保护内容。
2. 执行 P-M-S 分类、C 库检索和 `style_guide`。
3. 对 SVG Logo 做安全预检、高清栅格化和确定性贴放。
4. 生成候选，绑定新 `version_id` 与 SHA-256。
5. 执行 HC-01～HC-12；失败则定向返图并从 HC-01 重跑。
6. 消费者 Agent 查看当前候选并提交 25 项观察，由原 rc.3 脚本按原阈值计分。
7. 消费者通过后，兼容路由值 `aesthetic_agent` 被主流程解释为直接进入最终质量门。
8. 最终质量门执行消费者证据审计与无分数缺陷扫描；消费者可疑高分触发一次同图反向复核。
9. `TEXT_OVERLAP` 与 `LOGO_FLOATING` 至少为 moderate；局部返图冻结五个消费者锁与八组保护内容。
10. 返图从 HC-01→消费者→最终质量门完整复检；消费者回退即淘汰。
11. 所有成功返图共用最多 8 次预算；同一候选通过三道保留门禁才输出 `passed`。

与 rc.3 正式版相比，本实验只删除美学 Agent、A-D-AESTHETIC 输入、六维/25项美学评分、美学证据、美学锁和 `aesthetic-edit-lock`。C 库、ImageGen、Logo、硬合规、消费者门禁、最终质量缺陷规则、强制缺陷严重度和预算均保持不变；最终质量门仅做原有无分数缺陷仲裁，不视为美学评价替代品。
