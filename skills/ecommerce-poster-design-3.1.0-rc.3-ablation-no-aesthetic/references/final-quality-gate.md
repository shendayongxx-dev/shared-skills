# 最终质量仲裁：no-aesthetic 消融版

本门禁只在当前候选通过硬合规和消费者门禁后运行。必须查看原图、360px 缩图和商品参考；不输出第三套分数，也不替代被消融的美学 Agent。

## 模式与证据

- `standard`：核验消费者证据并扫描可见缺陷。
- `adversarial`：消费者分数命中 rc.3 可疑高分条件时，对同一候选执行一次反向复核；不生成、不计重画。

证据审计只接受消费者证据，不包含美学结果、分数、证据或锁。证据与画面矛盾、模板化、无位置或绑定到旧候选时，重评当前候选而不是重画。

## 固定扫描范围

1. 商品呈现：主体大小、遮挡、数量、透视、接触关系、阴影、包装和结构保真。
2. 信息层级：商品、标题、价格、促销、CTA 的焦点关系及 360px 可读性。
3. 排版：字体数量、字距、行距、对齐、安全边距、混排和假字。
4. 配色与场景：对比、强调色、商品背景分离、场景卖点关系、无功能装饰和模板感。
5. 完成度：边缘、材质、光源、清晰度和 AI 伪影。

最终质量门继续扫描这些 rc.3 可见缺陷，但不得据此生成专业美学总分或宣称美学门已通过。

## 严重度与强制路由

- `critical`：商品身份、数量、关键文字或品牌事实受影响。
- `severe`：主要商品、交易或阅读任务明显受阻。
- `moderate`：固定尺寸下可见、会造成退回、可定向修复。
- `minor`：不阻碍识别、理解和交易，只影响局部精修。

`TEXT_OVERLAP` 与 `LOGO_FLOATING` 至少为 `moderate`。必须给出区域与最小动作，不得因修复简单、仍可猜读或 Logo 清晰而降级。存在任一 moderate 以上缺陷或超过两个 minor 时生成 `final-quality-edit-lock-no-aesthetic/1.0`，默认 `local_edit_only`。

合同冻结五个消费者维度和八组保护内容。成功返图后重新执行 HC-01～HC-12、消费者评价和最终质量门；消费者回退即淘汰返图并恢复基线。

## 输出合同

严格输出 `assets/schemas/final-quality-review.schema.json` 定义的 `FINAL-QUALITY-3.1-ABLATION-NO-AESTHETIC` JSON，并携带：

```json
{
  "id": "no-aesthetic",
  "base_version": "3.1.0-rc.3",
  "aesthetic_artifacts_used": false
}
```

不得增加总分、维度分、美学字段或自由路由字段。
