# No-aesthetic 消融适配

## 实验边界

基线固定为 `ecommerce-poster-design-v3.1.0-rc.3`。唯一被移除的组件是美学 Agent 及其全部产物依赖。消费者 Agent 1.5.3、C 库、生成、Logo、硬合规、最终质量门、缺陷阈值和 8 次预算不变。

### 生成质量不变量

- 生成阶段仍执行基线的专业视觉设计，不得因缺少美学评估而降低构图、光影、材质、透视、场景融合或排版要求。
- 商品参考图必须在完整海报生成/编辑时直接参与场景整合。禁止把生成流程改造成“空背景生成 → 商品后贴”或“空背景生成 → 全部信息机械拼装”；这会引入第二个实验变量并使样本无效。
- Logo 的确定性后置应用保持不变，且仅限官方 Logo。应用前的候选必须已经包含自然融入场景的商品、完整光影与文字布局。
- 若执行路径改变了生成方式或主动降低画面质量，即使未调用美学 Agent，也不得记为有效 no-aesthetic 消融样本。

## 接口兼容

消费者模块保持字节级不改，其 A-D-2.0 Pass 仍返回 `next_route=aesthetic_agent`。这是模块接口兼容值，不代表本实验存在美学模块。主流程必须将它解释为 `invoke_final_quality_gate`。不得创建假的美学结果来满足旧接口。

## 锁与返图

消费者通过后冻结五个消费者维度与八组保护内容。最终质量门只能对已定位缺陷生成 `final-quality-edit-lock-no-aesthetic/1.0`，合同绑定当前候选、缺陷、可编辑区域、五个锁与保护内容。新候选从 HC-01 开始复检；任一消费者锁回退即淘汰并恢复最后消费者通过候选。

## 证据与反向复核

最终质量证据审计只接收消费者证据。rc.3 的消费者可疑高分阈值保持不变；美学相关阈值和审计字段被删除。反向复核仍只检查同一候选，不生成图片、不增加预算。

## 预算耗尽

候选必须先通过硬合规与消费者门禁才有资格参与降级选择。优先级为：最终质量已通过 > 缺陷最高严重度更低 > 加权缺陷总量更低 > 缺陷数量更少 > 消费者总分更高。不得使用美学分、缺失美学分的默认值或伪 Pass 排序。
