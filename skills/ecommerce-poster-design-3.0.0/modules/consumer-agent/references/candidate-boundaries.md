# 相邻档位边界与候选案例（1.5.3）

## 使用规则

每次评分读取本文件与subcriteria-anchors.md。下表是选档操作条件，不是81个案例的人工金标准。案例来自C组“电商视觉参考库_精简分类版”，2026-10-05读取81条分类说明，重点查看C-004、007、018、025、077、078、079、080、081图片；C-078仅第一张，C-081两张。没有完整原始brief和确认事实，不能称案例已验证高分。

- 先根据完整任务确定要求和关键购买疑虑，再盲观察当前海报；不要参考上一轮分数或看图后选择疑虑。疑虑只用任务支持的需求，不凭人群刻板印象补造。
- 先写当前图位置、可见内容、影响，再判断相邻边界。4档须满足该子项增强条件，不因风格、配色或整体好看升级。准确性事实项仍按既有规则确认正确为4、确认错误为0；不使用中档掩盖错误。
- 候选案例仅帮助识别表达关系，不将其价格、性能、官方身份、产品结构等转移到当前任务。不要求每次联网读案例；没有图像资产时不能假称重新核看案例。
- 读不清与确定不存在分开；本次必需事实未提供与确认错误分开。前者按输入/图像异常规则处理，不猜测0或4。已给事实的交接来源待确认不是事实缺失：重建来源、needs_human_review、缺分类版本等单独存在时按给定基准评分，不要求A/C额外认证每个已给参数；评分不等于事实独立认证或生产交接批准。
- 按任务决定是否必须价格、CTA和特定场景；N/A范围严格沿用现有D3规则。功能详情图不是完整促销任务的评分答案。
- P-M-S不改权重，标签不证明适配；场景可由文案、动作、结构或环境建立，不强制人物/背景。标签与brief冲突先交A/C核对，不擅自改标签。
- 同一缺陷主归属一个子项/维度，其余只记录影响，避免重复扣分。D2回答利益是否解释，D4回答锁定需求是否匹配，D5回答可信依据和具体疑虑是否成立。

## 易误判案例特征

- C-004：¥5旁有0元入会、满30元使用、新人入会礼。不得直接读为腮红5元售价。95%水精华和榜单需事实来源，底妆利益表达可用于D2_3，不自动证明功效。
- C-007：手拉置物架、高瓶、内高28cm形成特征—用途链。不能凭元数据说明声称图中有前后对比，也不证明未提供的承重。
- C-018：240%国家标准电量*1、原料说明是主张与限定标记；本次图片未见完整脚注，不能仅因大数字判D5_2为4。
- C-025：预估到手价219元/罐与入会再减10分别呈现，不自行算209元；0添加的配料表范围脚注是限定表达，不证明健康效果。
- C-077：血糖血压大字、TOP1、到手价显眼，不证明医学测量性能；核对任务事实而非颜色/排名。
- C-078：行走及坐姿体现实际使用，但库标签为节庆礼赠；使用者匹配不等于礼赠关系，不擅自纠正C标签。
- C-079：标准编号、过滤率、官方文字是待核对主张，不证明真实合规。本次图未见售价，不能描述有价。
- C-080：前仓放电脑是结构与利益联系，不证明容纳任意尺寸电脑；空间提升30%需核对范围，不要求额外机场背景。
- C-081：泛泛“售后无忧”与“365天内质量问题直接换新”有具体性差异；官方正品及充电比较仍需输入事实和条件支持。

## 验证与内部记录

### 同任务D5疑虑清单冻结

看图前只从Brief、确认卖点和锁定M/S建立清单，按任务中出现的需求顺序记录；每项写“疑虑—输入支持的回答—可观察表达”。已有清单在同一测试轨道中复用，不依据当前画面增删，不用上一轮得分作为依据。清单放D内部测试记录，不新增A-D字段；每次D5_4 evidence列出完整清单，便于比对。没有历史记录时按相同输入推导相同清单。
NORI-001当前任务固定清单：材质可靠性（316内胆）、出行温度保持（12小时保温保冷）、携带防漏（一键锁扣防漏随行）。不要求额外添加未给的健康认证、测试报告、温度工况或密封等级。
D5_4：2档为清单存在重要未回应项或仅泛泛保障；3档为各项有输入支持的具体回答；4档为各项回答清楚，且任务关键使用关系或必要条件已明确、无关键理解缺口。不能只选防漏一项代表全部，也不能因提供三项参数自动4档。
D5_2检查这些回答的事实支持与可理解性，不把未提供认证/测试当成必需缺失；D5_4检查疑虑与回答的对应关系。同一缺陷不得两次扣分。如果适用条件并非任务必要且输入未给，不能仅为争取4档要求新增；当前表达本已明确时允许满足4档。
改变疑虑清单或使用1.5.3边界后重新建立评分基线；不得为追平90/92分倒推档位。

输出仍用既有A-D-2.0和25子项draft结构；在evidence中写位置、可见事实及档位条件，必要时注明候选案例ID。不要新增正式输出字段。
两名评审用完整brief和事实独立校准候选，只标资料支持的子项；保存图版本、展示尺寸和争议条件。正式人工标签优先于候选描述。
固定任务、图像、模型和量表做独立重复评分，再用单变量退化/修复及未参与编写的留出案例检验。脚本回归通过只证明合同与计算未坏，不证明读图稳定或建议有效。
