# 最终质量仲裁：no-consumer 消融版

本门禁只在当前候选通过硬合规和美学后运行。必须查看原图、360px 缩图和商品参考；不输出第三套分数。

证据审计只核验美学证据，不包含消费者证据字段。美学总分≥92或 4 档子项≥18 时，对同图执行一次 adversarial 复核。

扫描商品呈现、层级、排版、配色场景和完成度。每个缺陷必须包含代码、类别、严重度、位置、可见事实、最小修复动作、允许编辑对象和保护对象。

- `critical`：商品身份、数量、品牌或关键文字事实受损。
- `severe`：主要商品、交易或阅读任务明显受阻。
- `moderate`：固定展示尺寸下可见且会造成退回，可定向修复。
- `minor`：不阻碍识别和交易，仅影响局部精修。

`TEXT_OVERLAP` 和 `LOGO_FLOATING` 至少为 `moderate`，不能因修复简单降级。任一 moderate 以上缺陷或超过两个 minor 时生成 `final-quality-edit-lock-no-consumer/1.0`。返图重新执行硬合规、美学和最终质量门。
