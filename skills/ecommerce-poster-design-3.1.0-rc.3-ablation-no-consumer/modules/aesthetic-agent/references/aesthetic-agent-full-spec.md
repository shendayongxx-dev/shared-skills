# 美学量表 no-consumer 适配说明

权威量表为 `assets/rubric.json`，保持 rc.4 的 25 子项、0～4 档、六维权重和最低贡献分：构图16/20、层级16/20、配色12/15、排版16/20、风格场景12/15、完成度8/10；总分至少80且无关键问题才通过。

输入不含消费者结果。评价者只能依据当前候选、商品参考、任务要求、P-M-S 和八组保护内容。缺失信息输出 `score=null`；不得用假定的消费者偏好补齐证据。

失败时最多返回三对问题与建议，每条包含对象与位置、允许编辑、禁止编辑、保护范围和原图/360px 验收点。局部问题优先 refine；不因缺少4档增强证据编造重绘理由。

文字覆盖、粘连或边缘冲突在排版观察中必须明确记录；Logo 缺乏邻近、对齐或容器关系而悬空时必须明确记录。最终严重度和重绘路由由主 Skill 的最终质量门确定。
